# Blog vs Code Review

This folder tracks whether what we write in our weekly blogs matches what is actually in the code.
Use it when putting together the final work, so the report, blogs and notebook all tell the same story.

| File | What's in it |
|---|---|
| [week-by-week.md](week-by-week.md) | Each week: what each blog says, what the code shows, and whether they match |
| [to-fix.md](to-fix.md) | Checklist of differences and loose ends to sort out before submitting |
| [rubric.md](rubric.md) | Marking rubric, where we currently stand on each criterion, and what to do to reach "Expectations Exceeded" |
| [polina-blog-todo.md](polina-blog-todo.md) | What Polina needs to add to her blog (Week 4 post + fixes to earlier posts) |

Last reviewed: 21 Oct 2026 (all posts up to Week 3, code up to commit `e9ed553` plus Polina's YUV matching cells).

## How to update

After each week's posts go up:
1. Read the new post from each of us.
2. Check `git log` for that week and look at the notebook.
3. Add a new week section to `week-by-week.md`.
4. Add anything that doesn't match to `to-fix.md`, and tick off items that are now fixed.
